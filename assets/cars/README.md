# سيارات اللعبة

تتضمن اللعبة ست سيارات رياضية خيالية قابلة للاختيار، تُنشأ مجسماتها محليًا باستخدام بدائيات Godot في `scripts/car_controller.gd`. تختلف في اللون والأداء وبعض تفاصيل الهيكل. لا توجد شعارات أو مجسمات منسوخة أو ملفات من شركات سيارات.

هذه التصاميم ليست سيارات Ferrari أو Lamborghini أو Toyota مرخصة أو نسخًا مطابقة لها، ولا نصرّح بارتباط تجاري بهذه العلامات. الأصول الخارجية الوحيدة المضافة في هذا الإصلاح هي خطوط Noto Sans Arabic المرخصة، وليست سيارات.

لرفع مستوى الجودة لاحقًا، يمكن استبدال المجسمات الإجرائية بملفات GLB/GLTF مرخصة، مع توثيق مصدر كل ملف وترخيصه هنا.
