# الخط العربي

تضمّن اللعبة الخطين `NotoSansArabic-Regular.ttf` و`NotoSansArabic-Bold.ttf` من عائلة Noto Sans Arabic لتوفير عرض عربي دون اتصال بالإنترنت. المصدر هو حزمة `fonts-noto-core` في Ubuntu 24.04، والخط من مشروع Noto التابع لـ Google.

الترخيص: SIL Open Font License 1.1، محفوظة كاملة في `OFL.txt`. لا توجد أصول سيارات أو شعارات تجارية ضمن مجلد الخطوط.
