# مواد البيئة الإجرائية

تُنشأ مواد طلاء السيارات والزجاج والزخارف المعدنية والأسفلت وعلامات المسار وواجهات المباني وأضواء الشوارع داخل `scripts/car_controller.gd` و`scripts/environment_builder.gd`. لا تعتمد اللعبة على تنزيل خامات أو حزم طرف ثالث. هذه مواد إجرائية منمّقة وليست صورًا واقعية ممسوحة ضوئيًا.
