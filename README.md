# Velocity Rush 3D

**مشروع سباق سيارات ثلاثي الأبعاد بـ Godot 4.4.1 — Android 9/API 28+ — يعمل دون إنترنت**

هذا مشروع Godot قابل للعب، بمضمار مدينة منحنٍ، وسيارات منافسة، ونمط قيادة حرة، وتحكم لمس، ووقود ونيترو، وواجهة عربية، وسير GitHub Actions لتصدير APK تجريبي.

> **حدود الأصول والجودة:** السيارات الست تصاميم خيالية تُنشأ إجرائيًا داخل اللعبة، وليست نسخًا مرخصة من Ferrari أو Lamborghini أو Toyota. لا يحتوي المشروع على شعارات تلك الشركات أو نماذج ثلاثية الأبعاد مرخصة منها، ولا يزعم أنه إصدار AAA تجاري. المدينة منمّقة وإجرائية، والأصوات محلية اصطناعية وليست تسجيلات حقيقية لمحركات سيارات. يمكن استبدال هذه الأصول لاحقًا بملفات GLB/GLTF مرخصة.

## ما يعمل في المشروع

- **سباق السرعة:** جولة مسافة بطول 850 مترًا، عدّ تنازلي، أربعة منافسين يتحركون على مسار الحلبة، ونتائج للوقت والمسافة والسرعة والاصطدامات والنقاط.
- **القيادة الحرة:** حلبة المدينة نفسها دون حد زمني أو شاشة خسارة، مع إمكانية إعادة تعبئة الوقود عند التوقف.
- **المضمار والمدينة:** طريق دائري بمنعطفات فعلية، علامات مسارات، حواجز وتصادمات، مبانٍ ونوافذ وأشجار وأضواء وسماء وإضاءة إجرائية.
- **المرآب:** ست سيارات خيالية قابلة للاختيار، باختلافات في اللون والأداء، مع حفظ السيارة المختارة محليًا.
- **الوقود:** يستهلك أثناء التسارع، ويظهر كمؤشر واضح؛ يتغير لونه عند الانخفاض. زر التعبئة متاح في القيادة الحرة عندما تكون السيارة متوقفة.
- **النيترو:** شحنة محدودة تُستهلك عند ضغط زر النيترو مع التسارع، ثم تُستعاد تدريجيًا.
- **واجهة قيادة عربية:** السرعة وRPM والوقت والمسافة والوقود والنيترو والتقدم، مع إيقاف مؤقت وتبديل الكاميرا.
- **التحكم:** مقود لمس افتراضي، أو أزرار يمين/يسار، أو إمالة الهاتف؛ ودعم مفاتيح WASD وShift للاختبار على الكمبيوتر. تدعم الدواسات اللمسية تعدد الأصابع.
- **الكاميرات:** مطاردة خلف السيارة ومشهد مقصورة مبسط.
- **الصوت:** محرك تتغير طبقته حسب دورات المحرك، ونيترو وفرامل وانزلاق واصطدامات ومؤثرات واجهة وموسيقى قائمة، مع تحكم بالصوت والموسيقى.
- **الإعدادات والحفظ:** جودة الرسوم، مستوى المحرك والمؤثرات والموسيقى، حساسية التوجيه، السيارة المختارة، وأفضل نتيجة/زمن في `user://velocity_rush_3d.cfg`.

## بنية المشروع

- `project.godot` — إعداد المشروع والمشهد الرئيسي والإضافات.
- `export_presets.cfg` — إعداد تصدير Android.
- `scenes/` — مشهد التشغيل والسيارة والحلبة والقيادة الحرة.
- `scripts/` — مدير اللعبة والسيارة والبيئة والسباق والكاميرا والصوت والحفظ والواجهة.
- `assets/fonts/` — خط Noto Sans Arabic، مع ترخيص OFL ومصدره.
- `assets/sounds/` — ثمانية ملفات WAV محلية وتخطيط حافلات الصوت.
- `icon.png` و`icon.svg` — أيقونة التطبيق.
- `.github/workflows/build.yml` — فحص المشروع وتصدير APK على GitHub Actions.
- `tools/validate_project.py` — فحص الملفات ومراجع الموارد وملفات الصوت والإعدادات.
- `AUDIT_REPORT.md` و`REPAIR_AND_QA_REPORT.md` — نتائج التدقيق والإصلاح والاختبارات والقيود.

## إنشاء APK عبر GitHub Actions

1. فك ضغط ملف المشروع وارفع **محتويات مجلد** `Velocity-Rush-3D` إلى جذر مستودع GitHub؛ يجب أن يظهر `project.godot` في الجذر.
2. افتح تبويب **Actions** وشغّل **Build VELOCITY RUSH 3D Android APK** يدويًا، أو ادفع commit/أنشئ Pull Request.
3. بعد نجاح المهمة، نزّل الأثر `Velocity-Rush-3D-Android-APK`؛ ويحتوي `VelocityRush3D.apk`.
4. ثبّت APK على هاتف Android. قد يطلب Android السماح بالتثبيت من مدير الملفات أو المتصفح.

يستهدف التطبيق Android 9/API 28 أو أحدث مع target API 35. يستخدم Workflow ‏Godot 4.4.1 وقوالب التصدير المطابقة، Java 17، Android SDK API 35، وNDK r23c. ويُجري فحصًا ساكنًا، واستيرادًا وتشغيلًا headless واختبارًا حتميًا لميكانيكيات اللعب، ثم يصدر APK موقّعًا بمفتاح debug. **هو APK للاختبار وليس توقيعًا جاهزًا للنشر على Google Play.** تُرفع سجلات CI منفصلة عن أثر APK.

## التشغيل محليًا

افتح `project.godot` في Godot 4.4.1 واضغط تشغيل. لتصدير Android من المحرر، ثبّت قوالب التصدير المطابقة واضبط مسارات Java 17 وAndroid SDK/NDK في إعدادات المحرر.

للفحص الأولي من مجلد المشروع:

```bash
python3 tools/validate_project.py
```

## عناصر التحكم

- **الهاتف:** اسحب المقود، أو استخدم أزرار الاتجاهات؛ اضغط باستمرار على التسارع أو الفرامل. استخدم النيترو مع التسارع. زر الوقود في القيادة الحرة متاح عند التوقف.
- **الكمبيوتر:** `W` للتسارع، `S` للفرملة، `A` و`D` للتوجيه، و`Shift` للنيترو.
- **الكاميرا:** زر الكاميرا يبدّل بين المطاردة والمقصورة. زر الإيقاف المؤقت يتيح الاستئناف أو العودة للقائمة.
